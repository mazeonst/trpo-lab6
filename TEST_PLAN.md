# План модульных тестов

1. Проверить сложение двух положительных чисел.
2. Проверить сложение положительного и отрицательного числа.
3. Проверить сложение нулей.
4. Проверить сложение с отрицательным результатом.
5. Проверить граничные значения `int`, если функционал калькулятора будет расширяться.
